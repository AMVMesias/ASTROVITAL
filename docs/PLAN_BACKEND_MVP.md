# Plan de integración vigente

1. Persistencia y autenticación en PostgreSQL de Supabase.
2. API Next.js desplegada en Vercel y frontend conectado por /api.
3. Primer acceso y recuperación reales; gestión de cuentas por administrador.
4. Registro manual, historial, entorno versionado, evaluación y avisos propios del astronauta.
5. Integración de hardware por HTTP autenticado con IDs estables y validación.

La arquitectura vigente está especificada en ESPECIFICACION_MVP_NASA_HEALTH.md. Las pruebas físicas del dispositivo y la validación científica de reglas y sensores requieren trabajo separado del despliegue web.
