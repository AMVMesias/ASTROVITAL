\block{1. Propuesta y alcance}
Prototipo web de monitoreo de salud con ESP32, ECG, pulso, SpO\textsubscript{2} y estimación respiratoria. Reúne captura BLE, historial, referencias personales y avisos de verificación. El contexto interior evalúa presión/O\textsubscript{2}, CO\textsubscript{2} e intensidad respecto a una FC máxima individual medida. Distingue datos simulados, ausentes y caducados; no diagnostica ni certifica seguridad de vuelo.
\block{2. Fuentes NASA realmente empleadas}
\begin{itemize}
\item \textbf{NASA OSDR RadLab: Curiosity / MSL-RAD, LRO / CRaTER-D1D2 y Orion Artemis I / EAD-MU01.} Resúmenes históricos de radiación incluidos en el código; no son dosimetría personal ni flujos en vivo. Conteos y percentiles aportados, sin reproducción de CSV originales.\\\url{https://visualization.osdr.nasa.gov/radlab/gui/overview/}\\\url{https://visualization.osdr.nasa.gov/radlab/gui/data-api/}
\item \textbf{NASA-STD-3001 Vol. 2 Rev. F, sección 6.2, tabla 6.2-1.} Fórmula de PiO\textsubscript{2}, referencias de oxígeno inspirado y CO\textsubscript{2} de cabina (promedio de una hora). El límite de cabina no se aplica al traje.\\\url{https://www.nasa.gov/wp-content/uploads/2025/05/nasa-std-3001-vol-2.pdf}
\item \textbf{NASA OCHMO-TB-031, Exercise Overview.} Fundamenta usar la FC máxima medida individualmente antes del vuelo como referencia de esfuerzo; no introduce multiplicadores por planeta.\\\url{https://www.nasa.gov/ochmo-tb-031-exercise-overview-2/}
\end{itemize}

{\Large Project descriptive brief}\par
\textbf{Team name:} 20\_Codengineers\par
\textbf{Challenge:} Create Health Monitoring Software for Astronauts on Space Missions.\par
\textbf{Team:} Mesias Mariscal (lead), Denise Rea, José Joaquín Silva Escobar, Gabriel José Freitas and Leonel Alejandro Tipan Quinto.\par
\textbf{Contact:} \href{mailto:mesiasmariscal@gmail.com}{mesiasmariscal@gmail.com}
\block{1. Proposal and scope}
Web health-monitoring prototype using ESP32, ECG, pulse, SpO\textsubscript{2} and movement-derived respiratory estimates. It combines BLE capture, history, personal baselines and verification notices. Interior context evaluates pressure/O\textsubscript{2}, CO\textsubscript{2} and intensity relative to an individually measured maximum HR. Simulated, missing and expired inputs remain explicit; no diagnosis or flight-safety certification is provided.
\block{2. NASA sources actually used}
\begin{itemize}
\item \textbf{NASA OSDR RadLab: Curiosity / MSL-RAD, LRO / CRaTER-D1D2 and Orion Artemis I / EAD-MU01.} Historical radiation summaries included in code; not personal dosimetry or live feeds. Supplied counts and percentiles have not been reproduced from original CSV files.\\\url{https://visualization.osdr.nasa.gov/radlab/gui/overview/}\\\url{https://visualization.osdr.nasa.gov/radlab/gui/data-api/}
\item \textbf{NASA-STD-3001 Vol. 2 Rev. F, section 6.2, table 6.2-1.} PiO\textsubscript{2} formula, inspired-oxygen references and cabin CO\textsubscript{2} (one-hour average). The cabin limit is not applied to a suit.\\\url{https://www.nasa.gov/wp-content/uploads/2025/05/nasa-std-3001-vol-2.pdf}
\item \textbf{NASA OCHMO-TB-031, Exercise Overview.} Supports using an individually measured preflight maximum HR for exertion context; no planet-dependent multiplier is introduced.\\\url{https://www.nasa.gov/ochmo-tb-031-exercise-overview-2/}
\end{itemize}
